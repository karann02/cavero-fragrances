## Category
E-commerce Luxury → Admin / Analytics Dashboard

## Style — Liquid Glass + Glassmorphism
- Frosted glass surfaces: `backdrop-filter: blur(15px) saturate(180%)`
- Translucent white fills: `rgba(255,255,255,0.15–0.50)`
- Subtle border: `1px solid rgba(255,255,255,0.2–0.6)`, light reflection, Z-depth
- Live emerald WebGL backdrop behind glass (kill-switch on reduced-motion / webdriver)
- AVOID: vibrant block-based color, playful palettes, ornate decoration, flat-without-depth

## Typography — Classic Elegant
- **Display headings:** Playfair Display (700) — luxury/editorial tone
- **Body / UI / labels:** DM Sans (400–700) — clean Inter-class sans (already loaded)
- **Numbers / data:** `font-variant-numeric: tabular-nums` to prevent column shift
- Scale: 12 / 14 / 16 / 18 / 24 / 28 · line-height 1.5 body

## Effects & Motion
- Fluid entrance: reveal-on-load (≤600ms, ease-out), staggered 40ms per item
- Float on hero stat cards (6s), card hover lift + glow ≤400ms
- Micro-interactions 150–300ms; **exit faster than enter**
- Respect `prefers-reduced-motion` (disables shader, float, reveal)

## Accessibility (CRITICAL)
- Text contrast ≥ 4.5:1; visible `:focus-visible` rings (2px teal) on all interactive elements
- Charts: `role="img"` + descriptive `aria-label` summary; legends; tooltips; empty/loading states
- Color never the sole signal (status pills carry text labels)
- Min 44px touch targets; keyboard operable

## Spacing & Shadow
- 4 / 8 / 16 / 24 / 32 / 48 rhythm
- Shadow scale: sm `0 2px 10px`, md `0 8px 32px rgba(26,49,44,.08)`, glow `0 0 25px rgba(66,132,117,.18)`

## Responsive breakpoints
375 / 576 / 768 / 992 / 1200 — mobile-first, no horizontal scroll, tables scroll inside their card.
